## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| SMB | Server Message Block: Protokoll für Datei- und Druckfreigaben |
| NFS | Network File System: Protokoll für Dateifreigaben unter Unix und Linux |
| Samba | freie Implementierung von SMB für Linux |
| UID/GID | numerische Benutzer- und Gruppennummer |

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

1. Siehe `beispiele/lauf.ausgabe.txt`: acht Zeilen, drei mit L (Anmeldung im Lauf, Samba-Version 4.19.5, Verschlüsselung SMB im Lauf), fünf mit F.
2. Beispiel: Windows-11-Abteilung: SMB; Linux-Entwicklungsrechner: NFS oder SMB; gemischtes Büro: SMB (Fachwissen, nicht bestätigt).
3. Beispiel: `samba` (Dienst `smbd`), `nfs-kernel-server`; Prüfung mit `systemctl status` (nicht ausgeführt).
4. `ping 10.55.0.2` von `win11` und `lx01`.

**Kontrollfragen (Antwortskizzen):**

1. Server Message Block; unter Linux setzt Samba es um.
2. SMB meldet Benutzer mit Passwort an (Samba-Datenbank oder Domäne); NFS vertraut klassisch den Angaben des Clients (AUTH_SYS) oder nutzt Kerberos.
3. Es gilt als veraltet und unsicher; im Lauf wurde es vom Server mit `server min protocol = SMB2` abgelehnt (Modul 7).
4. Bei AUTH_SYS gelten die numerischen Benutzer- und Gruppennummern des Clients; sie müssen auf beiden Seiten übereinstimmen.

</details>
