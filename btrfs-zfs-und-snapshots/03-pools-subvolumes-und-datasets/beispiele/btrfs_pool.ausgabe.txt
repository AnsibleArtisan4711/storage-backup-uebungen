
## 1. Dateisystem über zwei Platten: Daten und Metadaten gespiegelt (raid1)
$ mkfs.btrfs -q -f -L lernpool -d raid1 -m raid1 /dev/loop0 /dev/loop1
$ btrfs filesystem show /tmp/p34/mnt
Label: 'lernpool'  uuid: <UUID>
	Total devices 2 FS bytes used 144.00KiB
	devid    1 size 300.00MiB used 104.00MiB path /dev/loop0
	devid    2 size 300.00MiB used 104.00MiB path /dev/loop1


## 2. Subvolumes anlegen (sehen aus wie Verzeichnisse, haben aber eigene Eigenschaften)
$ btrfs subvolume create /tmp/p34/mnt/daten
Create subvolume '/tmp/p34/mnt/daten'
$ btrfs subvolume create /tmp/p34/mnt/home
Create subvolume '/tmp/p34/mnt/home'
$ btrfs subvolume list /tmp/p34/mnt
ID 256 gen 7 top level 5 path daten
ID 257 gen 7 top level 5 path home

## 3. Dateien in die Subvolumes schreiben
  drwxr-xr-x daten
  drwxr-xr-x home
  drwxr-xr-x verz

## 4. Ein Subvolume getrennt einbinden (wie eine eigene Partition) mit -o subvol
